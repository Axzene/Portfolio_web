# Portfolio, Personal Website

This is the first version of my personal portfolio website built using only **HTML5** and **CSS3**.

The project is being rolled out in phases. This version is only focused on building a clean, responsive and accessible frontend that meets the current assignment requirements. Future updates will include JavaScript functionality and backend integration.

 --- ## Features:

 - Semantic HTML5 structure 
- Responsive design
- CSS style sheet (external)
- CSS custom properties (:root)
- Flexbox and CSS Grid Layout
- Four major sections:
  - Introduction 
- A proposito di
- Projects 
- Reach out
- Accessible contact form with proper label-input pairing
 - Responsive design for desktop, tablet and mobile devices 
 - Hover effects and simple CSS transitions

 --- ### Design Decisions

For the first version I wanted to keep the layout simple without falling into a generic portfolio template. The website has warm beige and dark blue colour scheme. The design is clean and can be expanded later without changing the overall structure.

The project cards and overall page structure have been modularised, so that new content can be added easily in future updates.

--- ## Responsive design

The website has been designed with a responsive design.

Used breakpoints:

- Mobile: 480px and below
- Tablet: max-width 768px
- Desktop: more than 768px width

Flexbox and CSS Grid will make the layout adapt automatically to different screen sizes.
